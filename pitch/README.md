# Pitch - Aplicativo GAC

Apresentação web (HTML estático) do projeto **Aplicativo GAC - Gestão de Ativos do CCT/UNIFOR**.

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador.

## Estrutura

```
pitch/
├── index.html              # Página única do pitch
├── README.md
└── assets/
    └── images/
        └── logo-unifor.png
```

## Conteúdo

- Problema e contexto (CCT/UNIFOR)
- Público-alvo (Administrador, Atendente, Professor, Sistema)
- Solução proposta (stack React + Spring Boot + JWT)
- 17 funcionalidades agrupadas em 8 frentes (UC01–UC18, exceto UC16)
- Protótipo de baixa fidelidade (Figma) e demonstração ao vivo do protótipo de alta
- Benefícios por persona e impacto geral
- Equipe do projeto

## Geração de PDF

Ao imprimir/exportar para PDF pelo navegador, desmarque a opção **Cabeçalhos e rodapés** ("Headers and footers") em "Mais configurações" para evitar que o caminho do arquivo apareça no rodapé.
